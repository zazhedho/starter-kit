# Media module

Authenticated file upload to object storage (MinIO or Cloudflare R2) with metadata in PostgreSQL, and
owner-controlled deletion.

- Code: `internal/{domain,services,repositories}/media`, `internal/handlers/http/media`,
  `internal/router/media` (`wire.go`, `register.go`, `storage_adapter.go`), `internal/infrastructure/storage`,
  `internal/config/media.go`.
- Off by default: nothing is mounted unless `MEDIA_ENABLED=true`, and the storage provider is only opened
  then.

## Routes

Mounted under `/api` only when `MEDIA_ENABLED=true`. The list in `internal/router/media/routes_test.go` is
the source of truth.

| Method | Path | Auth | Notes |
|---|---|---|---|
| POST | `/api/media` | token (any authenticated user, no extra permission) | multipart form field `file`; `201` with the stored metadata; `400` for a missing, empty or unsupported file; `413` over the size limit; rate limited per client IP when Redis is configured |
| DELETE | `/api/media/:id` | token (owner or `superadmin`) | `:id` must be a UUID; `200`; `404` when the media does not exist or belongs to someone else (the response does not reveal which) |

Both routes write an audit entry (resource `media`, action create or delete) on success and on failure.
Object names are generated by the server, and the client's file name is reduced to its base name before it is stored as
`original_name`.

## Environment variables

| Variable | Default | Meaning |
|---|---|---|
| `MEDIA_ENABLED` | `false` | mount the media routes and open storage |
| `MEDIA_MAX_FILE_SIZE_MB` | `5` | largest accepted file, 1-1024 MB |
| `MEDIA_ALLOWED_CONTENT_TYPES` | `image/jpeg,image/png,image/webp,image/gif,application/pdf` | comma-separated accepted types |
| `MEDIA_UPLOAD_TIMEOUT` | `2m` | read deadline for one upload, replacing `HTTP_READ_TIMEOUT` for that route |
| `MEDIA_UPLOAD_RATE_LIMIT` | `20` | uploads allowed per client IP per window; must be above zero when media is enabled |
| `MEDIA_UPLOAD_RATE_WINDOW_SECONDS` | `60` | rate-limit window in seconds; must be above zero when media is enabled |
| `STORAGE_PROVIDER` | `minio` | `minio`, `r2`, `cloudflare` or `cloudflare-r2` |
| `STORAGE_ENDPOINT` | empty | storage endpoint, required |
| `STORAGE_ACCESS_KEY` | empty | required |
| `STORAGE_SECRET_KEY` | empty | required; never printed in logs |
| `STORAGE_BUCKET_NAME` | empty | required |
| `STORAGE_BASE_URL` | empty | public base URL of the bucket, required when media is enabled, must be a valid URL |
| `STORAGE_USE_SSL` | `false` | use TLS to reach the endpoint |
| `STORAGE_REGION` | `auto` | region |
| `R2_ACCOUNT_ID` | empty | Cloudflare account id, for the R2 provider |

Storage settings are also validated when any of them is set while media is disabled: the endpoint, both keys
and the bucket must then all be present.

## Table

`migrations/20260101000100_media_create_table.up.sql` creates `media`: `id`, `owner_user_id` (foreign key to
`users`, `ON DELETE RESTRICT`), `object_key` (unique), `url`, `original_name`, `content_type`, `size` (greater
than zero), `created_at`, `deleted_at` (soft delete: deleting a media marks the row, it does not remove it).

## Operational notes

### Storage requirements

- Enabling media requires a reachable storage provider with valid credentials and an explicit
  `STORAGE_BASE_URL`. The MinIO provider creates the bucket when it is missing (and applies a public-read policy
  to a bucket it creates); the R2 provider does not, so create the R2 bucket beforehand. A provider that cannot start is a startup failure (exit code 1).
- The module checks that storage was handed to it; if it is missing the error is
  `register media routes: storage is required when media is enabled`.

### Limits

- `HTTP_MAX_BODY_MB` (default `10`) must be larger than `MEDIA_MAX_FILE_SIZE_MB`; configuration validation
  fails otherwise when media is enabled.
- The upload route reads at most the file limit plus 1 MiB of multipart overhead; anything beyond answers `413`.
- The content type is detected from the file bytes. The client's extension and `Content-Type` header are not
  trusted. SVG is not in the default list because it can carry active content.
- Rate limiting needs Redis. Without Redis the upload route has no rate limit.

### Failure behavior

- If saving the metadata row fails after the object was stored, the object is deleted again.
- Deleting removes the stored object first, then marks the row deleted; if the object cannot be deleted the row stays active.
